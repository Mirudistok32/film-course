# Кино как способ мышления

Сайт курса визуального мышления: 13 уровней, 100 фильмов (из них 8 аниме), уроки «до / во время / после просмотра», журнал наблюдений, словарь, ранги и достижения, выпускная работа. Без сервера и аккаунтов: прогресс хранится в браузере, переносится JSON-файлом.

Требования — [docs/film-course-spec.md](docs/film-course-spec.md), принятые решения и отступления от ТЗ — раздел 2 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

## Как открыть

```bash
npm install
npm run build
```

Затем двойной клик по `dist/index.html`. Сервер не нужен: JS, CSS, шрифты и иллюстрации встроены в один HTML, адреса страниц — через `#` (`index.html#/film/nosferatu`). Тот же файл можно выложить на любой статический хостинг без настроек.

Для разработки — `npm run dev` (Vite с горячей перезагрузкой).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки |
| `npm run build` | Проверка типов → сборка → `scripts/postbuild.mjs` вкладывает JS и CSS в `dist/index.html` |
| `npm run typecheck` | `vue-tsc --build` |
| `npm run lint` | ESLint |
| `npm test` | Юнит-тесты Vitest (`tests/unit/`) |
| `npm run test:e2e` | Сборка и сценарии Playwright (`e2e/`) по `file://` в установленном Chrome: ноутбук и телефон 390 px |
| `npm run shots` | Скриншоты всех страниц и состояний в `.screenshots/` (светлая тема 1280 px и тёмная 390 px), заодно проверка ошибок консоли и горизонтальной прокрутки. `npm run shots -- film` — только снимки с `film` в имени |
| `npm run check` | Типы, линтер, тесты и сборка разом |

## Стек

Vue 3, TypeScript, Vue Router (hash-режим), Pinia, Vite. Тесты — Vitest + Vue Test Utils, e2e — Playwright. Шрифты — Ubuntu (заголовки), Roboto (текст), Tektur (подписи и цифры), woff2 с кириллицей лежат в `src/assets/fonts` вместе с лицензиями.

## Ограничения

- **Прогресс живёт в одном браузере.** `localStorage` (около 5 МБ) привязан к браузеру и устройству и стирается вместе с данными сайта. Защита — резервная копия JSON: кнопка на главной и на странице «Данные», напоминание, когда с последней копии изменилось 10 записей или прошло 3 дня занятий (можно отложить на неделю).
- **Несколько вкладок.** Вкладки синхронизируются через событие `storage`; если одно поле правят в двух вкладках одновременно, остаётся последняя запись.
- **Учебные тексты — редакционный черновик.** Уроки, образцы разборов и примеры словаря требуют проверки редактором. Уровни 3–13 и часть фильмов уровней 1–2 — предложенное расширение исходной концепции, это видно в интерфейсе.
- **Пустые поля каталога** (`runtimeMinutes`, `country`, `originalTitle`) не показываются, пока не заполнены и не проверены.
- **Ачивка «Не только сюжет»** определяет формальные решения в заметках по словарю киноприёмов — это эвристика; ошибка не влияет на прогресс курса.
- Фильмы на сайте не показываются: сайт — тренажёр, смотреть фильм нужно в другом месте.
