# Кино как способ мышления

Сайт курса визуального мышления: 13 уровней, 100 фильмов, уроки «до / во время / после
просмотра», журнал, словарь, ранги — личный тренажёр без бэкенда. Интерфейс, документация и
ответы — по-русски.

Общие принципы и имена команд — `../agent-base/docs/` (principles, conventions). Здесь —
только то, что отличает этот проект.

## Стек и запуск

- Vue 3 + Vite + TypeScript, Vue Router (hash-режим), Pinia. Не Next/React и не Vuex — выбор
  заказчика. Данные пользователя — `localStorage`, ключ `kino-kak-sposob-myshleniya:progress`;
  бэкенда нет.
- Открыть: `npm run build`, затем двойной клик по `dist/index.html` — без сервера, JS, CSS,
  шрифты и иллюстрации встроены в один HTML (`scripts/postbuild.mjs`). Разработка —
  `npm run dev`. Публикация: GitHub Pages на пуш в `master` (`.github/workflows/pages.yml`).

## Правила

- Ссылки — только `RouterLink` с именованными маршрутами; без `href="#id"` (hash-роутер примет
  за маршрут) и без абсолютных путей `/…` в `href` и `src`.
- Прогресс меняется только через стор: `store.apply(change)` с чистой функцией из
  `progress.actions.ts`; чтение — селекторы, логику в компонентах не дублировать.
- Дизайн: кинематограф + старое аниме + графика Артура Рэкхема; темы «пергамент» и «кинозал»,
  пастельные оттенки уровней `--tint-*`; шрифты Ubuntu / Roboto / Tektur. Иллюстрации — SVG в
  коде, без внешних картинок. Цвет только украшает — смысл передан текстом или формой.
- Контент: 13 уровней из ТЗ не трогать; аниме вплетено в уровни (8 фильмов), не отдельный
  уровень. Учебные тексты пишутся полностью и помечаются как черновик для редактуры.
- Неясное или важное по продукту — спрашивать, с вариантом по умолчанию.

## Проверки

- `npm run check` — быстрый гейт перед коммитом: типы, линтер, формат, юнит-тесты (без сборки);
  `npm run check:full` — `check` + `test:e2e` (сборка и Playwright по `file://`, ноутбук и
  телефон 390 px).
- `npm run contrast` — контраст текста по токенам обеих тем.
- Формат — Prettier (`.prettierrc.json`: без точек с запятой, ширина 120), `npm run format`.
  Markdown не форматируется (`.prettierignore`). После правки агента файл форматирует хук
  `.claude/hooks/format.mjs` (копия из agent-base).
- Визуально: `npm run shots` (все страницы и состояния в `.screenshots/`, ошибки консоли,
  горизонтальная прокрутка) или общий `/shots`.

## План

- Файл: `PLAN.md`, журнал: `PLAN-LOG.md` (сейчас плана нет). Пункт — `/next-task [N.M]`,
  прогресс — `/plan-status`.
- Гейт пункта: `npm run check:full`.
- Коммиты: не коммитить, пользователь коммитит сам.
- Ветка: `master`.

## Нельзя

- Менять и удалять ключи `localStorage` и id сущностей без миграции (`schemaVersion` и
  миграции — `docs/save-format.md`).
- Глушить правила линтера, удалять тесты, снижать пороги ради зелёного гейта.
- Ломать открытие с диска: `base: './'`, всё встроено в `dist/index.html`, hash-адреса.
